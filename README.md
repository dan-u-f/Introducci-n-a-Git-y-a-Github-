# Simple Interest Calculator

## Project Name
**simple-interest-calculator**

## Description
This project is a Bash-based command-line calculator that computes simple
interest based on user-provided input: principal amount, interest rate, and
time period. It was built as part of the final hands-on project for the
Introduction to Git and GitHub course, demonstrating the use of GitHub's
collaboration workflow (forking, branching, pull requests) and the Git CLI
(cloning, staging, committing, pushing, merging).

## Features
- Accepts principal, rate, and time as user input
- Computes simple interest using the formula: `SI = (P x R x T) / 100`
- Displays the result directly in the terminal

## How to Run
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
